## Preview of PCDJ Dex 3 Multitrack Mixing Software with Four Deck Interface and Tabbed Video Controls

[![](https://i0.wp.com/pcdj.com/wp-content/uploads/2014/06/dex2-4deckskinwithvideo.jpg?resize=640%2C270&ssl=1)](https://i0.wp.com/pcdj.com/wp-content/uploads/2014/06/dex2-4deckskinwithvideo.jpg?fit=640%2C400&ssl=1 "dex2-4deckskinwithvideo")

**DEX 3 DJ Software 4-Deck Video Mixing Tab Teaser** _(say that 5 times fast…_ _)_ 

PCDJ DEX 3’s release is almost upon us, and it will be PCDJ’s most robust and feature-forward **DJ software** and **video mixing** software ever. If you haven’t read up on what to expect when DEX 3 hit’s the street soon, you can review past posts regarding DEX 3 [**HERE**](https://tools.techidaily.com/pcdj/products/)

To sum it up, _DEX 3 is a re-design from the floor up._  The video mixing engine, graphics engine and media file (audio, video and karaoke) browser are all new – and have been designed so we can easily port DEX 3 to any operating system with relative ease. Yes, this means some significant upgrades are in store for our [**DJ DEX**](https://itunes.apple.com/us/app/dj-dex-the-dj-mixing-app/id514748680?mt=8) iOS app in the near future.  
  
**Below is the new video tab in the default 4-deck skin that will be included with the (free for DEX 2 users) upgrade. Some notable items are:**

* _**4 Full-Featured DJ Decks for Audio Mixing**_
* _**Top 2 decks are dedicated for video mixing/video effects**_
* _**Video mixing section can be swapped out for new “FX Grid” and/or a much improved Sampler**_
* _**Browser now has “side list/automix list” always present – album art and new list icons**_
* _**Larger search box area, and more (of course you can see the image below so I probably didn’t need to post any bullet points)**_

**DEX 3 4-DECK SKIN (VIDEO TAB)**
